## Comportamiento observado
Con el ratón: aviso de error → clic en «Reintentar» → éxito. El elemento de estado recibe el foco por programa y `.status:focus` dibuja un recuadro visible, aunque el usuario no usa el teclado.

## Comportamiento correcto (criterio)
El indicador de foco del elemento de estado solo se ve cuando el usuario navega con teclado (comportamiento de `:focus-visible`); con el ratón no aparece recuadro. El foco no se pierde en ningún caso (WCAG 2.4.3).

## Reproducción
1. Abrir la app con `/api/health` fallando.
2. Clic con el ratón en «Reintentar» con el servidor ya disponible.
3. «Conectado con el servidor» queda recuadrado.
